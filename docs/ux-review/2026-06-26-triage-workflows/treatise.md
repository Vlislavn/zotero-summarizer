# Principles for a simpler triage UI

```text
Scan → read evidence → decide → file
```

- Let the ranked list own the initial viewport; fold secondary filters.
- Show the suggested action separately from the user's saved verdict.
- Keep evidence before editable decisions on the full-paper page.
- Use one visual code per meaning; do not repeat a status as both icon and text.
- Disclose supporting detail rather than duplicating it across sections.
- Reuse shared controls across the decision card and full review.

For each change, remove redundant presentation first, then check keyboard
navigation, narrow layouts, readable labels, and explicit write consent using
synthetic data. These are design principles, not measured acceptance results.

Public provenance: [Laws of UX](https://lawsofux.com/), especially Hick’s Law,
Serial Position Effect, Miller’s Law, Von Restorff Effect, and Fitts’s Law.
See the [workflow guidance](README.md).
