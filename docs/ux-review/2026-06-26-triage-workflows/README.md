# Usability guidance — paper-triage workflows

```text
Ranked queue → decision card → full paper review → explicit filing
```

Keep the reading decision prominent and secondary controls quiet. Apply these
public [Laws of UX](https://lawsofux.com/) before adding controls:

| Law | Application |
|---|---|
| Hick’s Law | Keep the common filing action simple; disclose other destinations. |
| Serial Position Effect | Put ranked papers before secondary browsing controls. |
| Miller’s Law | Group related controls and avoid competing status codes. |
| Von Restorff Effect | Reserve emphasis for the primary action or a critical warning. |
| Fitts’s Law | Keep action targets large and close to their context. |
| Jakob’s Law | Reuse consistent verdict labels and familiar disclosure patterns. |

Subtract duplicate labels, repeated explanations, and unnecessary boxes before
adding controls. Distinguish cached suggestions from current model results and
human verdicts. Keep destructive actions secondary and writes explicit.
