# models — Pydantic contract (config + API shapes)

Every request/response body and the `goals.yaml` schema. Split by group; the
package `__init__` re-exports everything, so `from zotero_summarizer.models
import X` works unchanged.

```
config.py ──GoalsConfig──> api.py (AppState)
triage.py ──(domain)        all three ──*──> __init__.py  ──>  from ...models import X
```

| file | holds |
|---|---|
| `config.py` | `goals.yaml` schema: `GoalsConfig` + `LLMConfig`/`CorpusConfig`/`ClassifierGateConfig`/… (imports `PrestigeConfig`/`OpenReviewConfig` from `enrichment_config.py`) **`USER_OWNED_KEYS`** is the allowlist of human-authored keys (research intent + the LLM connection + `university_access`) that `services/_common.write_user_config` persists to `goals.yaml`; every OTHER section is a validated code default, overridable via `ZS_*` env (`services/config_overrides`, see `docs/overrides.md`) — so `goals.yaml` stays intent-only and old files with technical sections still load. `ClassifierGateConfig` defaults to `enabled: true` / `model_name: lightgbm` (PROVISIONAL, cold-start safe — the gate no-ops without a golden CSV). Migrates a legacy flat `llm:` block into `llm_routing` when the latter is absent. `CorpusConfig` carries the hybrid Library-search knobs (`bm25_enabled`/`reranker_enabled`/`reranker_model`, all local); `PrestigeConfig` carries the cold-start author-reputation prior (`cold_start_author_lift`/`cold_start_max_lift`/`cold_start_gamma`) — a capped, raise-only fallback to authors' field-normalized standing before a paper has its own citation percentile. `PrestigeConfig.enabled` now defaults **on** (OpenAlex is keyless + cached + fails soft to neutral); `ZS_OFFLINE` forces it off in `services/_common.read_config` and `ZS_PRESTIGE_ENABLED=0` opts out. `QualityReviewConfig.shadow_claim_check`/`claim_check_model` gate the Phase-A MiniCheck encoder shadow (off by default; needs the optional `minicheck` dep). `QualityReviewConfig` also carries the **tier-aware deep-review cost** knobs (`self_consistency_runs`/`lean_self_consistency_runs`/`lean_max_text_chars`/`batch_goal_summaries`) — a provider flagged `lean_deep_review` (e.g. ollama, prefill-bound) uses the cheaper `lean_*` caps + one batched goal-summary call, while every other provider (incl. MLX — loopback but fast) uses the full settings. The tier is keyed on the provider's `lean_deep_review` flag, NOT `is_local` (loopback ≠ lean). `QualityReviewConfig.prewarm_on_startup_k` (default 5, `0` disables; env override `ZS_DEEP_REVIEW_PREWARM_K`) drives the **launch-time deep-review prewarm** (`services/library/deep_review_prewarm.py`). `QualityReviewConfig.render_on_tick_k` (default 3, `0` disables; env `ZS_QUALITY_REVIEW_RENDER_ON_TICK_K`) is how many TOP Today feed papers also get the full heavy paper RENDER per daemon tick (`services/triage/feeds/_tick._auto_render_slate`; built from the cached in-place review + cached PDF, no extra LLM). `QualityReviewConfig.quality_band_primary` (default off; env override `ZS_QUALITY_BAND_PRIMARY`) flips the order-time quality lift from grade-only (the shipped default) to band-primary — a Phase-2-measured arm read by the shared `services/_common.band_primary_enabled` and applied via `model/rank_blend.quality_bonus`. `QualityReviewConfig.self_verification` (default on) gates the second-pass over-claim check on critical met items; `use_docling` (default off, optional `docling` dep) swaps the fitz PDF path for structured tables + figure captions. `review_web_articles` (default **on**) renders a web article (blog/Substack/news with HTML full text but no PDF) to a PDF so the fleet can review it for RELEVANCE only — the review routes it to the `NON_PAPER` type (no scientific A–D grade; see `services/library/paper_type`/`quality_eval`) via the `web_article` acquire flag (`_pdf_acquire`'s web-article rung; needs the `browser` extra). `max_pdf_bytes` defaults to **50 MB** (`QualityReviewConfig` + `FullTextRefineConfig`) — figure-heavy clinical/Nature PDFs run >20 MB. `RecoverAbstractConfig` (default ON: `goal_sim_threshold` 0.45, `max_per_tick` 3, `min_abstract_chars` 120) drives the daemon's **acquire-before-score rescue** — a gate-rejected, abstract-less, high-goal item (prestige-journal RSS ships no real abstract) gets its full text fetched + re-scored before the verdict stands (see `services/triage/README.md`). `UniversityAccessConfig` (off by default) configures the review fleet's **browser** PDF fetch for non-arXiv/paywalled papers: `enabled`, optional `ezproxy_prefix` (blank = SSO/OpenAthens, the persisted session carries access), `login_url`, `browser_profile_dir` (blank = `data/browser_profile` via Settings), `headless`, `fetch_timeout_secs`, `cookie_browser` (reuse an existing browser's session via `browser-cookie3` — chrome/firefox/edge/brave; Safari is unreadable on macOS 15+/26), and `browser_channel` (default `chrome`: drive the REAL Chrome binary so its fingerprint matches the injected `cf_clearance` and aggressive Cloudflare publishers like Nature/npj accept it; `""` = bundled chromium) — needs the optional `browser` extra (patchright + browser-cookie3). |
| `enrichment_config.py` | `PrestigeConfig` (OpenAlex author/venue prestige — cold-start author-reputation prior `cold_start_author_lift`/`cold_start_max_lift`/`cold_start_gamma`; `enabled` defaults **on**, `ZS_OFFLINE` forces off, `ZS_PRESTIGE_ENABLED=0` opts out) + `OpenReviewConfig` (authenticated OpenReview peer-review SEARCH source: `venues`/`year_min`; creds are `OPENREVIEW_USERNAME`/`OPENREVIEW_PASSWORD` env, read at point-of-use by `integrations/openreview.py`, never this config; SIGNAL-ONLY — surfaces a `services/search` display chip, never a rank input; `ZS_OFFLINE` also forces it off). Split from `config.py` for the 500-LOC limit; re-exported via `models.config` |
| `feeds_config.py` | `FeedsConfig` — the `feeds.*` daemon section (tick cadence `daemon_tick_seconds`/`daemon_batch_size`, RSS refresh rotation `max_feeds_per_pass`/`max_new_items_per_feed`/`per_feed_timeout_secs`, read-marking `mark_processed_as_read` + `zotero_read_sync` (the Zotero unread-badge reconciler, default on), dedup toggles (`dedup_against_processed=None` follows `dedup_against_library`), outcome cadence, daily-selection scheduling, `inbox_collection_name`, `exclude_feeds`). System-owned, so every scalar auto-derives a `ZS_FEEDS_*` override — before this section, `feeds.*` was raw-dict passthrough that `GoalsConfig` silently dropped from goals.yaml, making the knobs unsettable. Split from `config.py` for the 500-LOC limit; re-exported via `models.config` |
| `providers.py` | per-stage LLM routing: `ProviderConfig`/`ProviderType`, `StageModelConfig`, `LLMRoutingConfig`, `resolve_stage()` (stage → effective provider+model, inheriting `default`). `ProviderConfig.is_local` flags loopback endpoints (→ serial triage concurrency); `ProviderConfig.lean_deep_review` opts a provider into the cheaper deep-review tier (independent of `is_local` — set on ollama, left False on MLX); `ProviderConfig.max_sub_concurrency` caps how many deep-review SUB-calls (rubric samples / per-goal summaries) fan out in parallel on a remote provider (`None` → fall back to `TRIAGE_JOB_CONCURRENCY`; ignored for local providers, which stay serial). `ProviderConfig.temperature` (default `0.0`, the previously-hardcoded deterministic-triage value) is threaded into the openai-path `build_llm`; the native Anthropic adapter ignores it (Opus rejects the param). `ProviderConfig.thinking_effort` (`off`/`low`/`medium`/`high`, default `None` = leave untouched) is translated per backend dialect by `services/llm/thinking.py` (anthropic → thinking budget; plain OpenAI → `reasoning_effort`; vLLM/qwen `chat_template_kwargs` → `enable_thinking` on/off — graded collapses there). `ProviderConfig.thinking_on` (computed: `thinking_effort != "off"`) is what the deep-review DIGEST reads to decide `enable_thinking` — the digest reasons by default (measured NEEDED) and a provider set to `thinking_effort: off` opts it out, with no separate toggle. `ProviderConfig.num_ctx` (default `None`) auto-derives for LOCAL providers in `services/_common._derive_local_num_ctx` (`max_text_chars/4 + max_tokens` ×1.25 headroom — ollama's own ~2–4k default silently truncates a long deep-review prompt) and is forwarded as `extra_body.num_ctx`; remote providers stay `None` (they size their own window). `ProviderConfig.keep_alive` (default `None` = off) is the ollama warm-hold (seconds a LOCAL model stays loaded after a call); a LATENCY knob, not correctness, so it is OFF by default and NOT auto-derived (pinning a model resident grows steady-state RAM — unsafe on a memory-constrained Mac), forwarded as `extra_body.keep_alive` only when set explicitly (PROVISIONAL, GAP §G6). `ProviderConfig.structured_output` (default `False`) opts a provider into decoder-level JSON (`response_format json_schema strict`) for the digest — MEASURED trade-off (forces enum/range + reasoning survives, but completeness drops 1.00→0.62 and needs a roomy `max_tokens`); enable only for models prone to invalid JSON (see `docs/internal/knowledge_map.md` §D). Pure data + lookups — no env reads, no client building. |
| `triage.py` | `SummarizeRequest/Response`, `TriageResult/Dimensions`, `QualityReview`, `PaperParameters` (verbatim full-text dataset/baseline/sample/metric/architecture/validation extraction), `PaperDigest` (the single `read|skim|skip` action plus targets, time, original value, optional parameters, and grounded low/moderate/high writing friction; high friction caps read to skim; old rows load through defaults), `GoalSummary` (grounded per-goal evidence), `QualityEval` (reference-free checklist/band, evidence, flags, agreement and optional MiniCheck shadow), `ProposedVerdict` (deterministic display-only priority suggestion), batch/corpus/calibration models |
| `api.py` | HTTP request/response + write-path models (`*Request/*Response`, `AppState`, Zotero/pending shapes) |
| `setup.py` | the FROZEN `/api/setup/*` contract: `SetupStatusResponse` (+ nested `ConfigStatus`/`LlmStatus`/`PathStatus`/`PathEntry`/`ZoteroStatus`/`ClassifierStatus` + a `subsystems: list[SubsystemStatus]` runtime-readiness array, additive — a not-ready entry names the down subsystem + reason without affecting the top-level `ready`), `DetectedZoteroDir`/`DetectZoteroResponse`, `UpdatePathsRequest`/`UpdatePathsResponse`, `ValidateConfigRequest`/`ValidateConfigResponse` (+ `FieldError`/`ConnectionResult`). SECURITY: `api_key_env` is only ever an env-var NAME; key presence is the BOOL `api_key_present` — no model here carries a secret value |
| `__init__.py` | re-exports all of the above (the public `models` surface) |

**Boundaries:** depends only on `pydantic` + `domain`. Nothing here imports
`services/`/`storage/`/`api/`.
